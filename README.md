# WiseConcepts Sports GFX updates



This repository distributes signed, encrypted Windows update packages for the WiseConcepts Sports GFX desktop application.



- Installed apps check this repository without a GitHub account or access token.

- Updates are signed with Ed25519; packages are encrypted with AES-256-GCM.

- The running app verifies and decrypts releases before offering installation.

- Installation always requires the operator's choice. Graphics operations take priority.

- For a new PC, obtain the initial installer from the WiseConcepts team. The encrypted release asset cannot be run directly.



No sync secret, decryption key, signing key, or readable installer is published here.
